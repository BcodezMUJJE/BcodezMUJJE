### Bug Bounty Toolkit & Workflow

I follow a structured CLI-based approach for recon and vulnerability testing, optimized for GitHub Codespaces.

**Phase 1: Reconnaissance**
- `subfinder` – Subdomain enumeration  
- `nmap` – Port scanning, service detection, and NSE scripts  
- `dns-brute` – Brute-force subdomains using Nmap  

**Phase 2: Discovery & Enumeration**
- `dirsearch` – Directory brute-forcing on web servers  
- `httpx` – Filter live web servers from subdomain list  

**Phase 3: Vulnerability Scanning**
- `nmap --script vuln` – CVE and service-based script scan  
- `nuclei` – Large-scale vulnerability scanning using community templates  
- Custom scans for XSS, SQLi, CSRF, misconfigs, Heartbleed, weak SSL

**Phase 4: Manual Testing**
- `httpie` / `curl` – API endpoint fuzzing and request crafting  
- `ffuf`, `kiterunner` – Parameter fuzzing & API route scanning  

**Setups & CLI Tools That Work in Codespaces**
| Tool         | Type | Works in Codespaces | Use Case |
|--------------|------|---------------------|----------|
| subfinder    | CLI  | ✅ Yes              | Subdomain discovery |
| dirsearch    | CLI  | ✅ Yes              | Directory brute-forcing |
| nuclei       | CLI  | ✅ Yes              | CVE and misconfiguration scanning |
| httpie/curl  | CLI  | ✅ Yes              | Manual request crafting |
| Burp Suite   | GUI  | ❌ No               | Run locally only |
| Postman      | GUI  | ❌ No               | Use `httpie` in Codespaces instead |
