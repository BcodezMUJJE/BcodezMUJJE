## About Me

Software Engineer, Cybersecurity Analyst, and CTO based in **Kampala, Uganda**. I build secure, scalable full-stack systems using the MERN stack, Python, and Flutter/Dart, with a strong emphasis on clean architecture and defensive design. 

My work spans frontend engineering, backend API development (including Flutterwave payment integrations), database design, and security hardening. Alongside building cloud-based applications via Project IDX, I actively conduct security research and submit vulnerability reports (XSS, IDOR) on HackerOne. I have a growing interest in quantum computing and its intersection with machine learning, and I approach every project as a system design problem first, not just a feature delivery problem.

Currently overseeing technical development as the **Chief Technology Officer at EduSens Africa**.
