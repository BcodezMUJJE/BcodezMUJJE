## 🏗️ Architecture & Engineering Focus

* **Database-First Design:** I design highly normalized PostgreSQL schemas, leveraging materialized views and strict constraints to maintain data integrity before it ever reaches the application layer.
* **Type-Safe Ecosystems:** Extensive use of TypeScript across the stack to ensure interfaces between the frontend, API, and database (via generated types) remain perfectly synchronized.
* **BaaS Integration:** Deep expertise in Supabase—implementing secure Row Level Security (RLS) policies, utilizing Edge Functions for serverless compute, and configuring real-time data subscriptions.
